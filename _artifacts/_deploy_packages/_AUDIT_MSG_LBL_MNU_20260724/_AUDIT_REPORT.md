## 한계 (정직 고지)

- 패키지 토큰 매칭은 **텍스트 기준** — VERIFY/진단 스크립트에만 등장하는 ID 도 "포함"으로
  집계되므로 실제 INSERT 커버리지는 이보다 더 낮을 수 있음 (누락 323 은 하한).
- **UPDATE 계열 미집계**: 기존 seed row 의 문구 정정(LAST_UPDATED_BY 만 작업 계정)은 본
  감사 범위 밖 — 별도 추출 필요 시 LAST_UPDATE_DATE 기준 2차 감사.
- 2026-03~05 등록분 63건은 클라우드 DB 시드 시점에 따라 이미 반영돼 있을 수 있음
