# MSG 동기화 — 클라우드 추출본 1개 → 사내 오라클 반영

## 쓰는 법 (2단계)

```
1) 클라우드에서 SCM_ADM_MSG_M 을 CSV/TXT 로 내보낸다.  (형식 자유)
2) 그 파일 경로를 주고 아래를 돌린다.

   python msg_update.py <파일>              # 판정 + SQL 생성만 (아무것도 바꾸지 않음)
   python msg_update.py <파일> --apply-db   # 사내 DB 실제 적용
   python msg_update.py <파일> --apply-ui   # FE 소스 코드 치환 실제 적용
```

**입력 형식은 신경 쓰지 않아도 된다.**
**JSON**(SQLcl `results/items` · 단순 배열 · `{items}`/`{data}`/`{rows}` · JSON Lines — 소문자 키,
NULL 컬럼 키 생략 허용) 과 **CSV/TSV**(구분자 `,` `\t` `|` `;`) 를 모두 받는다.
인코딩(UTF-8/BOM/CP949), 헤더 유무·컬럼 순서·컬럼명 변형(`MSG_ID`/`MESSAGE_ID`/`msgid` …),
따옴표 안의 콤마·개행까지 흡수한다. 판별 결과는 리포트 `0_요약` 에 그대로 찍힌다.

## 무엇을 하는가

| # | 상황 | 처리 |
|---|---|---|
| **A** | 코드 동일 · 명칭 상이 | 사내 명칭을 **클라우드 기준으로 UPDATE** |
| **B** | 사내에 코드 없음 | **신규 INSERT** |
| **C** | A 인데 그 코드를 **사내 UI 가 쓰고 있음** | 아래 C-1 / C-2 |
| C-1 | 클라우드에 **옛 명칭을 가진 다른 코드**가 있음 | UI 를 **그 코드로 치환** |
| C-2 | 없음 | **신규 코드 채번**(01001+) → 옛 명칭으로 사내 INSERT → UI 치환 → **클라우드에도 INSERT** |

> **C 가 A 를 안전하게 만든다.** C 없이 A 만 하면 그 코드를 쓰는 다른 화면이 조용히 오표기된다.
> (2026-08-14 확정 규약: "기존 코드에 명칭을 변경하면 기존 프로그램에 다른 TEXT 로 보이는 치명적 오류")

사내 단독 보유 행은 **삭제하지 않는다**. 리포트에만 올린다.

### 사내에서 "UI 가 쓰는 곳" 으로 보는 4축

- FE/BE 소스 코드 리터럴 (`nscm-fe/features|apps|packages`, `nscm-be/src`) — 화면ID 자동 귀속
- `SCM_ADM_MNU_M.MNU_MSG_ID` — 메뉴 표시명. 이 테이블엔 메뉴명 컬럼이 없어 **이 축이 유일**하다
- `SCM_ADM_API_M.API_MSG_ID`
- `SCM_ADM_LOOKUP_MASTER_DETAIL.SEGMENT2`

않고 `비인용` 으로 남겨 사람이 판단한다.

적용 후에는 locales 를 다시 만든다 — BE 기동 상태에서 `cd nscm-fe && node scripts/sync-i18n.mjs`.

## 안전장치 (모두 실측 검증됨)

1. **채번은 01001+ 대역 MAX+1**, 그것도 **사내 + 클라우드 양쪽**을 함께 본다. 대역 밖 이상치
   (`MSG99999` = 테스트 행)는 MAX 계산에서 뺀다. → 실측: `MSG01016` / `MNU01001` 정확 산출.
2. **차이의 성격을 5분류한다.** `공백차이` / `표기차이`(구두점·간격) / `번역채움` / `언어퇴행` /
   `의미변경`. **의미변경만** UI 치환·신규 채번 대상이다. 구두점 하나로 코드를 따면 안 된다.
3. **값을 트림하지 않는다.** 사내 원장엔 뒤 공백이 실재한다(`MNU00185 = 'Biz Plan Price '`).
4. **언어퇴행 기본 제외.** 클라우드 EN/CN 칸에 한글이 들어온 행은 사내 번역을 지킨다.
   덮어쓰려면 `--allow-lang-regression` + 사용자 승인.
5. **순환 치환 안전.** `A→B`·`B→A` 상호 교환이 실재한다. FE 소스는 **정규식 1패스 동시 치환**,
   DB 메타는 **임시 센티널 경유 2단계 UPDATE**(FK 없음 실측). 순차 처리하면 뒤가 앞을 되돌린다.
6. **조용한 누락 차단.** 각 SQL 말미에 `-- STMT_COUNT: n` 을 남기고, `--apply-db` 는 분해 결과가
   그 수와 다르면 **실행하지 않고 중단**한다.
7. 감사컬럼은 `admin` 으로만 기록한다. 적용 전 백업·원복본을 항상 생성한다.

## 한계

- C-1 후보가 여러 개면 코드순 첫 번째를 고르고 `치환근거` 에 후보 수를 남긴다. 전 언어 일치가 없으면
  `KO 부분 일치` 등으로 낮춰 잡으므로, 그 행은 사람이 확인하는 편이 좋다.
- `비인용`(주석·식별자) 치환은 자동으로 하지 않는다. 2026-08-21 적용분 기준 42곳이 남아 있다.
- 화면 실동작(런타임) 검증은 하지 않았다. 문구가 바뀐 화면은 사용자 확인이 필요하다.
- 참고 실측: `SCM_ADM_API_M.API_MSG_ID` 300종 중 **114종만** `SCM_ADM_MSG_M` 에 실재한다(186종 dangling).
  이 도구는 실재하는 코드만 '사용중' 으로 센다.
