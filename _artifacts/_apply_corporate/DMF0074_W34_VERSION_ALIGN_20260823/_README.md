# DMF0074 Excel Form 0건 정정 — W34 원장/마스터 버전 정합 (사내 적용 완료 2026-08-23)

## 증상
DMF0074 → Excel Form → Search 시 **"다운로드할 템플릿 대상 데이터가 없습니다."**(MSG01015 / 구 MSG00656).
사용자 재현: 화면에서 버전 `SP_W_20260820_V002`(W34) 선택 상태.

## 원인 (실측)
`P_DMF0074_GET_METAL_LINK_TEMPLATE` 은 **화면에서 고른 버전을 쓰지 않는다**
(파라미터 = `P_DIVISION_ID / P_USER_ID / P_MENU_ID` 3개, FE 도 `divisionId/sesUserId/mnuId` 만 전송).
SP 가 스스로 `MAX(VERSION_NO) FROM DM_MST_VERSION WHERE DIVISION_ID=:div AND VERSION_TYPE='SP_W'` 로
기준 버전을 정하는데, 그 버전(`SP_W_20260820_V002`)의 원장 `DM_PLN_SALES_PLAN_C` 가 **0행**이었다.

| 축 | 상태 (2026-08-23 실측) |
|---|---|
| `DM_MST_VERSION` | system 배치가 08-21 까지 계속 SP_W 행 생성 (08-14 7 / 08-18 3 / 08-19 13 / 08-20 3 / 08-21 7) |
| `DM_PLN_SALES_PLAN_C` | 마지막 갱신 **2026-08-17 20:10**. div 40 = 200만행 / 39버전 |
| 교집합 | div 40 은 **2026-05-13 이후 마스터의 모든 SP_W 버전이 원장 0행**. 반대로 원장 최신 `SP_W_20260817_V001`(28,085행)·`SP_W_20260730_V001/V002` 는 마스터에 미등재(고아) |
| 범위 | 8개 division 전부 MAX 버전 원장 0행 (40/81/81_HD/81_HG/81_HM/81_ST/81_UC/82) |

반증 실험(읽기 전용): 기준 버전만 `SP_W_20260817_V001` 로 바꾸면 원장 통과 2,722행 → 조인 최종 2,703행.
⇒ **SP 로직·조인·MRF 조건 문제 아님. 기준 버전에 데이터가 없던 것이 유일한 원인.**

## 조치 (사용자 승인 2026-08-23 — "원장을 마스터에 맞춤" / 범위 "div 40 만")
`DM_PLN_SALES_PLAN_C` div 40 의 `SP_W_20260817_V001` 28,085행 → `VERSION_NO='SP_W_20260820_V002'` UPDATE.
같은 주(W34 = 2026-08-17 월 ~ 08-23 일) 스냅샷이라 기간 산식(RESULT_TO~PLAN_TO) 결과가 동일하다.

- 실행: `apply.py` (점검 `--dry`)
- 백업: `SCM_MGR.BAK_DMF0074_SPC_W34_20260823` (28,085행 CTAS)
- 감사컬럼 **미변경** (AS-IS 스냅샷 원본 보존 — 변경 이력은 본 폴더 + 백업표가 담당)
- 안전장치: 타깃 버전 0행 선확인(PK 15컬럼에 VERSION_NO 포함 → 충돌 방지) / 마스터 MAX 재확인 /
  UPDATE 건수 ≠ 사전 실측 시 ROLLBACK / 트리거 0·비파티션 확인

## 남은 일 / 주의

1. **근본 원인 미해결** — 주간 SP_W 배치가 버전 행만 만들고 `DM_PLN_SALES_PLAN_C` 스냅샷을 적재하지 않는다
   (div 40 기준 2026-05-13 이후 전량). 배치/데이터 담당 확인 필요. 본 조치는 W34 1주분 임시 정합이다.
2. **나머지 7개 division 미조치** — 동일 증상. 원장 보유 최신 버전(대부분 `SP_W_20260817_V001`)과
   마스터 MAX(`SP_W_20260821_V001`)가 어긋나 있다. 81_ST 는 원장 최신이 2026-05-22(9행)뿐이라 별도 판단.
3. ⚠ **중복 리스크** — 이후 배치가 `SP_W_20260820_V002` 를 정상 적재하면 PK 충돌(ORA-00001)로 실패할 수 있다.
   배치 재수행 전 본 조치를 원복하거나 해당 버전 행을 정리할 것.
