> 본 문서 = 재명명을 빼고 남는 **실제로 해야 할 작업**만 실측 기반으로 정리.

## §0. 왜 재명명이 불요한가 (근거 요약)

`ALL_TABLES.DURATION` 실측 — GTT **전량이 세션/트랜잭션 단위 격리** (`SYS$SESSION` 1,988 / `SYS$TRANSACTION` 382).
→ 여러 사용자가 같은 GTT 이름을 써도 **데이터 락은 발생하지 않음**. 세션마다 별도 temp segment.
→ 동시 사용 시 실제 경합은 **`TRUNCATE TABLE`(DDL)** 이 유발하는 **library cache / cursor / row cache mutex** 이다.

**결정적 반증**: DMF0082 는 이미 `GT_DMF0082_*` 접두를 26종에 적용했지만,
**그 접두 GTT 들에 대해 `TRUNCATE` 19건이 그대로 남아 있다** → 접두를 붙여도 경합 원인이 제거되지 않았다.
즉 **이름이 아니라 `TRUNCATE` 가 원인**임이 실측으로 확인됨.

## ✅ 작업 A (핵심) — `TRUNCATE TABLE` → `DELETE FROM` 치환 **81건**

근거 룰: **hook #107 `sp-hang-runaway-loop-diagnosis`** (사내 실사고 DMF0014 Excel Upload 무반응)
> "GTT `TRUNCATE`(DDL) 동시세션 mutex 경합 hang → **전량 `DELETE FROM` 치환** + 잔존 0 검증"

GTT 는 세션별 격리이므로 `DELETE` 로 바꿔도 **결과 동일**(내 세션 데이터만 삭제), DDL 이 사라져 경합만 제거됨.

### A-3. 치환 규칙
```sql
-- 정적
TRUNCATE TABLE SCM_MGR.GT_XXX;            →  DELETE FROM SCM_MGR.GT_XXX;
-- 동적 (DMF0082 L2946 등)
EXECUTE IMMEDIATE 'TRUNCATE TABLE SCM_MGR.GT_XXX';  →  DELETE FROM SCM_MGR.GT_XXX;
```
⚠️ 동적(`EXECUTE IMMEDIATE`) 형태는 **정적 DELETE 로 바꾸면 의존성이 생기므로** 오브젝트 재컴파일 대상이 됨(정상).
⚠️ 대량 행 GTT 는 `DELETE` 가 느릴 수 있음 → 배포 후 조회 소요시간 비교 필요.

## ⚠️ 작업 B (별건 결함) — `GT_PRDM_T_MAIN` vs `GT_PRDM1_T_MAIN` **이름 불일치로 기능 no-op**

**실측 확정** (`ALL_DEPENDENCIES`):
| GTT | 사용 오브젝트 |
|---|---|
| `GT_PRDM1_T_MAIN` | `PKG_DMF0082` — **여기에 적재(INSERT)** |
| `GT_PRDM_T_MAIN` (무 `1`) | `PR_DM_PLN_CFM_TO_MKT_FCST` — **여기서 읽음(SELECT)** |

→ **완전히 다른 GTT** 이므로 DMF0082 저장 후 `PR_DM_PLN_CFM_TO_MKT_FCST` 로의 **40 전파가 사실상 no-op**.
메모리 `feedback_div81_table_branch_conventions` 에 "잠재결함(미수정)" 으로 기록돼 있던 건이 **실측으로 확정**됨.

> 이는 재명명 작업과 무관한 **기존 기능 결함**입니다. 수정하려면 어느 쪽 이름이 정본인지 업무 확인이 필요합니다(양쪽 DDL·컬럼 동일 여부 확인 후).

## §5. 진행 절차 (승인 시, 오브젝트 단위 순차)

1. 오브젝트별 백업 → `TRUNCATE TABLE X` → `DELETE FROM X` 치환 (**기대건수 assert + 라인수 대조 + 주석 보호**)
2. BE 정지 → `DDL_LOCK_TIMEOUT` 배포 → `VALID` / `USER_ERRORS 0`
3. **잔존 검증**: `TRUNCATE` 0건 (동적 문자열 포함)
4. 조회 회귀(행수·result cursor 동일) + **소요시간 비교**(DELETE 성능 확인)
5. 전 화면 완료 후 **동시 세션 경합 실측**(`V$SESSION` event 전·후 비교) — 효과 검증
