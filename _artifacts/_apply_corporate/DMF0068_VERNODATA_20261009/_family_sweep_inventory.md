# 형제 패턴 정적 인벤토리 — 버전 테이블(DM_MDF_VERSION / DM_MST_VERSION) 단일행 `SELECT … INTO` (사내 ZIOUI1, 2026-10-09 14:5x ALL_SOURCE)

> 조회: `FROM DM_(MDF|MST)_VERSION` 줄의 앞 8줄 안에 `INTO v_…` 가 있는 문장 (INSERT/MERGE/BULK 제외). **구조 판정(가드 유무·AS-IS 의도) 전 — 리터럴 출현 ≠ 결함.**
> DMF0068 L434(적용 후 줄)은 본 작업으로 가드됨. 나머지는 ① 집계(COUNT/MAX/NVL(MAX))·DUAL EXISTS = 안전 ② 배치 SP 에서 버전 미존재 = AS-IS 도 실패 의도일 수 있음 ③ 화면 GET 에서 FE 입력 버전 조회 = DMF0068 동형 후보 — 각 자리의 AS-IS 원문 대조가 필요하다. 후속 감사 범위는 사용자 결정 대기.

원시 조회 SQL:
```sql
SELECT F.NAME, F.TYPE, I.LINE INTO_LINE, F.LINE FROM_LINE, TRIM(I.TEXT)
  FROM ALL_SOURCE F JOIN ALL_SOURCE I ON I.OWNER=F.OWNER AND I.NAME=F.NAME AND I.TYPE=F.TYPE AND I.LINE BETWEEN F.LINE-8 AND F.LINE-1
 WHERE F.OWNER='SCM_MGR' AND F.TYPE IN ('PACKAGE BODY','PROCEDURE','FUNCTION')
   AND REGEXP_LIKE(F.TEXT,'FROM\s+(SCM_MGR\.)?DM_(MDF|MST)_VERSION','i')
   AND REGEXP_LIKE(I.TEXT,'(^\s*INTO\s+|\sINTO\s+V_|\sINTO\s+[A-Z_]+\s*$)','i')
   AND NOT REGEXP_LIKE(I.TEXT,'INSERT|MERGE|BULK','i')
 ORDER BY F.NAME, F.LINE;
```
