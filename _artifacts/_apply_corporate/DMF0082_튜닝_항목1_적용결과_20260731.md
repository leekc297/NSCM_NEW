→ **접두 집합을 `GROUP BY` 로 1회 선계산 후 JOIN** 하는 방식으로 전면 재작성. 사내 실측: `[1]` **0.28초** / `[2]` 3개 division 동시 **0.49초** (기존 division 분할 실행 불필요). div82 포함 3 division 모두 집계_불일치 0 / 키_불일치 0 재확인.

