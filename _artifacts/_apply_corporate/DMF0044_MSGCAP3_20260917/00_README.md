### ⚠ 요약 문구는 기존 원문 유지 — `... 외 N건`

요청하신 예시는 `"이외 3건 발생"` 이었으나, 현재 문구 `... 외 N건` 은
**2026-09-15 에 사용자 지정으로 확정된 포맷**(`[E20260915-DMF0044MSGFMT]`)입니다.
같은 화면의 문구 규약을 임의로 바꾸면 그 지정과 충돌하므로 **건수 상한만 변경**하고 문구는 보존했습니다.
문구까지 `이외 N건 발생` 으로 바꾸길 원하시면 1행 추가 수정으로 즉시 반영 가능합니다.
