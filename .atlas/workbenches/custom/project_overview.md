# NSCM

> 이 문서는 **모든 AI 세션(챗·activity)의 공통 맥락**이다 — 프로젝트에 맞게 수정·보강하라.

## 진행 방식

- stage 는 .atlas/workbenches/custom/stages/<id>/ 폴더로 구성된다(폴더가 진실). 선후 관계는 stages/stages.yaml.
- 각 stage 의 activity 를 실행해 산출물을 만들고, 결과는 사람이 검토한다.

stage 추가는 `atlas stage add`(또는 앱의 탭 +)로, 스킬 작성은 .atlas/workbenches/custom/activities/guide.md 를 참조.
