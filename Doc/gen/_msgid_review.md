# 기존 화면 메시지 ID 검토 목록 — 2026-10-23

AS-IS 와 TO-BE 는 같은 MSG ID 를 다른 문구에 쓴다(MSG00001 AS-IS '모든 항목은 필수 입력입니다.' / TO-BE '저장 하시겠습니까?').
아래는 **그 화면이 AS-IS 에서 쓰던 MSG ID 가 페이지 코드에 그대로 있고 TO-BE 에서 뜻이 다른** 곳이다(게이트 MS1 기준, 주석 제외).
TO-BE 뜻으로 일부러 쓴 것(예: MSG00002 = TO-BE '성공적으로 저장되었습니다.')이면 그대로 두고 같은 줄에 `// MSG-OK` 를 달고, AS-IS 뜻이면 → 오른쪽 TO-BE ID 로 바꾼다. `MSG?????` = TO-BE 에 같은 문구 없음(신규 등록 MSG01001+).
