> ⭐ 정본: 사용자 지정 보완요청(단위테스트 시트·대조 문서·대화)의 생애주기 단일 원장.
> 게이트 소비: `asis_mapping_gate.py --check`(REQ 축) / 러너 섹션 10. 룰 = hook `request-ledger-and-subclause-mapping`.
>
> ⭐⭐⭐ **미적용 전제 원칙 (사용자 확정 2026-08-20)**: 시트 지정 검증 시 전 항목 초기 상태 = `PENDING`.
> 기존 문서의 '완료' 표기·이전 세션 판정·기억은 상태 전이 근거가 될 수 없다. `PENDING → 전이`는
> **착수 시점 실측(코드 위치 + 실행/DB)** 근거를 근거 칸에 기입한 경우에만 허용. 근거 없는 전이 = 게이트 FAIL.
>
> 상태 enum: `PENDING`(미적용 전제) / `APPLIED`(코드 반영·실측 근거) / `VERIFIED`(실행·DB 실측 통과)
> / `USER-DECISION`(사용자 결정 대기 — 소멸 금지, 게이트 보류 목록 상시 출력) / `VISUAL`(육안 확인 대기 — 동일)
> / `EXCLUDED`(해당없음·철회 — 사유 필수).
> 판정신호 문법: `FE:정규식`(페이지 폴더) / `SHARED:정규식`(nscm-fe 전체) / `EV:경로::정규식`(증적 파일)
> / `!FE:정규식`(부정 — 0건이어야 충족), `;;` 로 복수. `(미정 …)` = 파일럿/작업 시점에 실측으로 확정.
