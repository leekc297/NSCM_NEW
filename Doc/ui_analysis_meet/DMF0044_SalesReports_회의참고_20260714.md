# DMF0044 Sales Reports — UI 분석 회의 참고 (2026-07-14)

> **화면**: DMF0044 / AS-IS `DMF0044_Sales_Reports` (`GSCM.DM.Plan.UIL`) / TO-BE slug `sales-reports` (**미구현**)
> **업무 성격**: 판매 리포트(Sales Report) — 버전 선택 후 **조회 중심** 화면 (입력 아님. [[DMF0021]] 0709 회의 "리포트에 속으시면 안 됨" 연장)
> ⚠ **자매 화면**: [DMF0049 ETC Sales Reports](DMF0049_SalesETCReports_회의참고_20260714.md) 와 POPUP(`DMF0044_Sales_Version`/`DMF0044_United_Version`) 공유 — 두 화면은 짝으로 분석.
> 표기 원칙: 음성인식 원문 보존, 해석은 `(추정: …)` 병기.

## ㉮ 확정 사항 · 핵심 규칙

1. **리포트 타입 → 버전 접두 자동 스탬프** — "세일즈 플랜이면 **SP 버전**으로, 비즈 플랜이면 **BP 버전**으로 찍힘". 리포트 타입(Sales Plan / Business Plan)에 따라 생성 버전의 접두가 SP_ / BP_ 로 구분됨 (00:01 단락)
2. **권한 = Admin 전용** — "세일즈 리포트 권한은 **어드민 권한을 가진 사용자만** 있음" (07:58 단락). [[DMF0021]] 0709 회의 "3개 화면(비즈니스 플랜·세일즈 리포트·ETC 세일즈)을 40 사업부만 씀" 과 정합.
3. **카피 = 선택 버전 복제 + 신규 버전 채번** — "선택한 버전의 데이터를 카피해서 **버전을 새로 따주는** 구조". 최신 데이터로의 갱신이 아니라 원본 버전 스냅샷 복제 (00:01 단락)
4. **⭐ 카피 시 환율 = 버전별 컷오프 시점 환율 (최신 환율 금지)** — "데이터 카피할 때는 최신 환율을 쓰는 게 아니고 **각 버전별 컷오프 시점 환율로 버전별로 같이 움직이는** 거임". 버전에 환율이 고정 동반 (07:58 단락)
5. **데이터 타입 = ALL → 컷오프 데이터 + ETC 데이터 조인 조회** — "데이터 타입 올로 하면 **컷오프 데이터와 etc 데이터를 조인**해가지고 조회시켜주는 것". ETC 원천은 [DMF0049](DMF0049_SalesETCReports_회의참고_20260714.md) (07:58/00:01 단락)
