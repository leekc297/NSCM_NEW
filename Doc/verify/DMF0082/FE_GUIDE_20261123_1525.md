# DMF0082 Forecast & Price 조회 'Sql Error' (종료일 'Invalid Date') FE 가이드

- DB 쪽 적용: 없음. PKG_DMF0082.P_DMF0082_GET_MAIN_DATA 338줄은 종료일이 8자리 숫자가 아니면 오류를 냄(-20002). 잘못된 기간으로 조회하지 않게 막는 장치라 그대로 둠
- 근거: 운영 로그 SCM_COM_SYS_LOG 2026-11-23 eunjung_heo FcstNPrice SEARCH 3건. 화면이 보낸 종료일(toYyyymmdd) = 'Invalid Date'. 사내 DB 같은 문구 오류 SSP0060 32건(최근 30일)
- FE 반영 전 주의: 항목 1만 반영하고 항목 2를 빼면 종료일이 빈 값으로 넘어가 같은 338줄 오류가 'Sql Error' 로 계속 뜸

## 항목 1. 기간 입력 칸이 틀린 날짜를 'Invalid Date' 글자로 넘김

1. 무엇이 문제인지
   - 종료일 칸에 날짜를 직접 치다가 형식이 틀리면(예: 2027.04.3 까지만 입력) 조회 조건 종료일에 'Invalid Date' 글자가 들어감
   - 조회를 누르면 그 글자가 그대로 DB 로 가서 화면에 'Sql Error' 가 뜸
2. AS-IS 동작
   - 기간 칸 drpPeriod 는 달력 컨트롤이라 날짜 값만 가짐. 조회 때 drpPeriod.Value1, Value2 를 날짜로 읽음(DMF0082_FcstNPrice_Mgmt.cs:1691, 1699)
   - 틀린 날짜가 SP 로 넘어가는 경로 없음
3. 고칠 곳
   - nscm-fe/features/master/src/components/searchFields/SearchFields.tsx:1215 (시작일)
   - nscm-fe/features/master/src/components/searchFields/SearchFields.tsx:1232 (종료일)
   - 공용 기간 칸이라 이 칸을 쓰는 화면 파일 71개에 같이 반영됨
4. 변경 전 / 변경 후

```tsx
// 변경 전 (1215)
onChange(date?.format(outFormat) ?? '', end);
// 변경 전 (1232)
onChange(start, date?.format(outFormat) ?? '');
```

```tsx
// 변경 후 (1215) 틀린 날짜는 빈 값으로 넘김
onChange(date && date.isValid() ? date.format(outFormat) : '', end);
// 변경 후 (1232) 틀린 날짜는 빈 값으로 넘김
onChange(start, date && date.isValid() ? date.format(outFormat) : '');
```

5. 확인 방법
   - 자동 시험: 종료일 칸 onChange 에 dayjs('2027-13-45') 를 넣으면 onChange 두 번째 값이 '' 로 나와야 함. dayjs('2027-04-30') 이면 '20270430'
   - 화면: 종료일 칸에 2027.04.3 까지만 입력하고 칸 밖을 누름 → 조회 조건 종료일이 비어 있음. 'Invalid Date' 글자 없음

## 항목 2. 조회 버튼이 종료일 형식을 확인하지 않음

1. 무엇이 문제인지
   - 조회 전 확인은 시작일 > 종료일, 3년 초과만 봄. 종료일이 'Invalid Date' 나 빈 값이어도 조회가 나감
   - 탭에 저장된 조회 조건에 'Invalid Date' 가 남아 있으면 항목 1을 고쳐도 다시 열 때 같은 오류가 남
2. AS-IS 동작
   - 기간이 틀리면 조회하지 않음. 3년 초과 때 MSG00164 를 띄우고 멈춤(DMF0082_FcstNPrice_Mgmt.cs:1699~1705)
3. 고칠 곳
   - nscm-fe/features/demand/src/pages/forecast-price/ForecastPrice.tsx:453~458
4. 변경 전 / 변경 후

```tsx
// 변경 전
const from = searchParams.startYyyymmdd;
const to = searchParams.endYyyymmdd;
if (from && to && from > to) {
  await setAlert({ type: 'alert', content: t(MSG.PERIOD_ORDER, '_Invalid period.') });
  return;
}
```

```tsx
// 변경 후 시작일, 종료일이 8자리 숫자가 아니면 기간 오류 안내 후 멈춤
const from = searchParams.startYyyymmdd;
const to = searchParams.endYyyymmdd;
const isYmd = (v: string) => /^\d{8}$/.test(v ?? '');
if (!isYmd(from) || !isYmd(to) || from > to) {
  await setAlert({ type: 'alert', content: t(MSG.PERIOD_ORDER, '_Invalid period.') });
  return;
}
```

5. 확인 방법
   - 자동 시험: 조회 조건 종료일 = 'Invalid Date' 로 조회를 누르면 MSG00108 안내가 뜨고 조회 요청 0건. 종료일 = '' 도 같은 결과. 종료일 = '20270430' 이면 조회 요청 1건
   - 화면: 종료일을 지우고 조회 → MSG00108 안내, 'Sql Error' 없음
   - 운영 반영 뒤: CLOUD_SAVE_HISTORY_20261123.sql [4] 에서 DMF0082 'Invalid Date' 오류 0건
