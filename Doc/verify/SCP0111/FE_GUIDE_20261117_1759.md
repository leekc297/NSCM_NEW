## G1. ADMIN 계정이 이미 있는 행을 고쳐 저장할 때 보내는 값을 AS-IS 와 같게 변경

### 무엇이 문제인지

- ADMIN 계정이 INV 행 월 수량을 고치고 저장하면 저장되지 않음(11-03 DB 보완 기준)
- ADMIN 계정이 INV 가 아닌 행의 BOH 를 고치면 BOH 는 그대로이고 첫 달 수량에 BOH 바뀐 양이 더해짐
- 원인: FE 가 바뀐 셀 1개와 바뀐 양만 보냄. ADMIN 저장은 AS-IS 에서 월별 BOH 와 월 수량을 화면 값 그대로 보내는 방식임

### AS-IS 동작 (`SCP0111_IntegrationPSI.cs` 1283~1368줄)

| 경우 | 보내는 월 | BOH 값 | 월 수량 값 |
|---|---|---|---|
| BOH 를 고친 행 | 조회 기간 전체 월. 원래 값이나 화면 값이 빈 월은 뺌(1299줄) | 화면 BOH | 그 월 화면 값 |
| BOH 는 그대로, 월 수량만 고친 행 | 값이 바뀐 월만(1342줄). 빈 월은 뺌(1333줄) | 화면 BOH | 그 월 화면 값 |

- INV 행과 그 밖의 행을 나누지 않음
- 조회 기간 = 조회할 때의 From~To 월(1154줄). TO-BE 에서는 행에 들어 있는 6자리 월 칸이 같은 범위임
- 일반 계정 저장은 AS-IS 도 바뀐 양을 보냄(1560, 1603줄). 일반 계정 쪽은 고치지 않음

```ts
// 빈 값 판정: AS-IS `ToString() == string.Empty`(cs:1299, 1333). 0 은 값이 있는 것으로 본다
const isBlank = (v: unknown): boolean => v === undefined || v === null || s(v).trim() === '';

// ADMIN 계정 수정행 1행의 저장 셀 목록(AS-IS cs:1283~1368)
//   BOH 를 고친 행: 조회 기간 전체 월(빈 월 제외), BOH 와 월 수량 = 화면 값
//   BOH 가 그대로인 행: 값이 바뀐 월만, BOH 와 월 수량 = 화면 값
export const unfoldAdminModifyCells = (
  row: Row,
  changed: Record<string, unknown>,
  base: Omit<SaveCell, 'action' | 'yyyymm' | 'modiQty'>,
  fixedBindings: ReadonlySet<string>
): SaveCell[] => {
  const orig = (b: string): unknown => (b in changed ? changed[b] : row[b]); // 수정 전 값
  const nowBoh = num(row.BOH_QTY);
  const bohChanged = num(orig('BOH_QTY')) !== nowBoh;
  const months = Object.keys(row)
    .filter(b => isYyyymm(b, fixedBindings))
    .sort();
  const out: SaveCell[] = [];
  for (const ym of months) {
    if (isBlank(orig(ym)) || isBlank(row[ym])) continue; // cs:1299, cs:1333
    if (!bohChanged && num(orig(ym)) === num(row[ym])) continue; // cs:1342
    out.push({
      ...base,
      action: 'M',
      yyyymm: ym,
      bohQty: String(nowBoh),
      modiQty: String(num(row[ym])), // 화면 값 그대로
    });
  }
  return out;
};
```
