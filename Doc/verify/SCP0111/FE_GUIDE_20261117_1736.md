### AS-IS ADMIN Modify 규칙(cs:1283~1368)

1. 수정 전 BOH(조회 원본) ≠ 화면 BOH 이면 조회 기간 전체 월을 보냄.
   - 월마다 `원본 월값 == ''` 또는 `화면 월값 == ''` 이면 그 월 제외(cs:1299~1300)
   - `p_boh_qty` = 화면 BOH, `p_modiQty` = 화면 월값(절대값), `p_yyyymm` = 그 월
2. BOH 가 같으면 원본 월값 ≠ 화면 월값인 월만 보냄.
   - 같은 빈값 제외 조건 적용(cs:1333~1334)
   - `p_boh_qty` = 화면 BOH, `p_modiQty` = 화면 월값(절대값)
3. MEASURE 로 분기하지 않음. INV 행과 그 밖의 행이 같은 규칙임.
4. 조회 기간 = `periodFromDate`~`periodToDate`(cs:1154). TO-BE 에서는 행에 실린 6자리 월 바인딩(`isYyyymm`)이 같은 범위임.

### 변경 후

```ts

      cells.push(...unfoldAdminModifyCells(row, changed, base, fixedBindings));
      continue;
    }
    // GENERAL = 기존 코드 그대로(가감값 · BOH 는 plan start 월)
    for (const binding of Object.keys(changed)) {
      ...변경 없음...
    }
```

```ts
// 값 없음 판정: AS-IS `ToString() == string.Empty`(cs:1299, 1333). 0 은 값 있음
const isBlank = (v: unknown): boolean => v === undefined || v === null || s(v).trim() === '';

// ADMIN 수정행 1행 → 저장 셀(AS-IS cs:1283~1368)
//   BOH 변경: 조회 기간 전체 월(빈 월 제외), bohQty=화면 BOH, modiQty=화면 월값
//   BOH 같음: 값이 바뀐 월만, bohQty=화면 BOH, modiQty=화면 월값
export const unfoldAdminModifyCells = (
  row: Row,
  changed: Record<string, unknown>,
  base: Omit<SaveCell, 'action' | 'yyyymm' | 'modiQty'>,
  fixedBindings: ReadonlySet<string>
): SaveCell[] => {
  const orig = (b: string): unknown => (b in changed ? changed[b] : row[b]);
  const nowBoh = num(row.BOH_QTY);
  const bohChanged = num(orig('BOH_QTY')) !== nowBoh;
  const months = Object.keys(row)
    .filter(b => isYyyymm(b, fixedBindings))
    .sort();
  const out: SaveCell[] = [];
  for (const ym of months) {
    if (isBlank(orig(ym)) || isBlank(row[ym])) continue; // cs:1299 · cs:1333
    if (!bohChanged && num(orig(ym)) === num(row[ym])) continue; // cs:1342
    out.push({
      ...base,
      action: 'M',
      yyyymm: ym,
      bohQty: String(nowBoh),
      modiQty: String(num(row[ym])), // 절대값
    });
  }
  return out;
};
```
