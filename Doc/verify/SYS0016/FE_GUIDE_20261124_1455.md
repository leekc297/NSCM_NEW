## 1. 첨부파일 올리기 서버 경로 없음

1. 무엇이 문제인지: 공지 등록 창에서 첨부파일을 고르면 업로드 오류가 남
2. 화면 동작: 첨부 업로드 함수 `useAttachmentUpload` 가 `/file/upload` 로 파일과 분류값 `fileKdnCd=NOTICE` 를 보냄
3. 고칠 곳: nscm-be/src/main/java/com/lgcns/nscm/general/file/FileController.java:75 아래. 화면 쪽 호출 줄은 nscm-fe/features/admin/src/pages/notice-setup/useAttachmentUpload.ts:21
4. 변경 전 / 변경 후

```java
// 변경 전: 이미지 올리기(/file/image-upload), 이미지 보기(/file/image/{fileId}), Excel 올리기만 있음

// 변경 후: 첨부파일 올리기 경로 추가
// 받는 값: file, fileKdnCd
// 돌려줄 값: fileId, fileName, size, ext, url (화면 AttachmentUploadResult 와 같은 이름)
// 저장 위치: 이미지와 같은 첨부 표 SCM_COM_ATCH_FILE_M
@AuthCheck(Type.LOGIN)
@PostMapping(value="/file/upload", produces = "application/json; charset=UTF-8")
public ResponseEntity<BaseResponse<AttachmentUploadResponse>> fileUpload(
        @LoginUser UserSession userSession
        , @RequestParam("file") MultipartFile file
        , @RequestParam(value = "fileKdnCd", required = false) String fileKdnCd

}
```

5. 확인 방법
   - 테스트 케이스: 1KB txt 파일을 올리면 `fileId` 가 비어 있지 않고 `size=1024` 가 돌아와야 함. 실행 파일(exe)은 오류가 돌아와야 함
   - 화면: 공지 등록 창에서 pdf 1개를 올리면 첨부 목록에 파일명과 크기가 보여야 함
