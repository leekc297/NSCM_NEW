## 2. Working Time Default 칸을 비울 수 없음 (CheckList V-70799fba · 2026-11-19 00:3x 측정)

2. AS-IS 동작: 칸을 비울 수 있고 저장 때 빈값을 0 으로 바꿔 보냄(SCP0096_Shipment_Working_Day_OSP.cs:568~569 → p_working_time_default)

- 화면 범위 검사(ShipmentWorkingDayOspGrid.tsx:288)는 빈값을 통과시킴
- 남은 후보: 편집 종료 뒤 값을 되돌리는 처리(ShipmentWorkingDayOspGrid.tsx 편집 이벤트), 화면 자료 갱신 처리. 다음 CheckList 가 칸 편집기 isRequired 값을 근거에 남김
