### 6-2. 헤더 구조 (2단 / 다단 헤더)

- **헤더 높이 48px** (y=224–272) = **2-depth**. 상단 그룹행(y=224, h≈24) + 하위 컬럼행(y=248, h≈24).
- path 클러스터 분석: 좌측 고정영역 텍스트(x 262–1230, n=14) + 월/연도 그룹(x≥1230, n=22) → **좌측 고정 컬럼 + 우측 연/월 컬럼** 2-depth.
- 데이터 행: y=272 부터 **행높이 25px**, 약 26행 표시(y=272,297,322,…,920). 짝수/홀수 구분 배경(일부 `#6E706F` 톤 없음, 단색).
- 우측 정렬 숫자 셀: 각 행 x≈1082 위치에 28.9×9.9 텍스트(수치 값) 반복 → 측정값(measure) 컬럼.
