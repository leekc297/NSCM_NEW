## §0 사용자 명시 요구 (2026-08-08 — 본 hook 의 존재 이유)

> "현재까지의 보완 및 검증에 대하여 rule 을 MD hook 에 기재해서 앞으로 신규 ui 와 보완 시 검증까지 진행되도록 해주세요.
> **실제 검증완료까지 되지 않으면 검증완료로 회신하지 않고 반드시 오류로 표기하고 보완해주세요.**"

**계약**: 보고 상태는 **2 값이 아니라 3 값**이다.

| 상태 | 의미 | 회신 허용 |
|---|---|---|
| **PASS** | 검증 축 전부가 **실행되어** 통과 | ✅ "검증 완료" |
| **ERROR** | 검증이 **실행되지 못했거나 · 미수행 · 결과 미확인** | ⛔ **"완료" 금지 — ERROR 로 표기 + 보완** |
| **FAIL** | 실행되었고 **결함이 확인됨** | ⛔ **"완료" 금지 — 결함 명시 + 보완** |

⛔ **핵심 금지**: **"검증하지 못한 것"을 "문제 없는 것"으로 회신하지 않는다.**
미실행·미확인·환경파손·도구 미지원은 전부 **ERROR** 이며, PASS 도 WARN 도 아니다.

## §1 금지 표현 ↔ 필수 대체 표현

| ⛔ 금지 (미검증 상태에서) | ✅ 필수 대체 |
|---|---|
| "검증 완료" / "완료했습니다" | "**ERROR — {축} 미검증**. 사유: {사유}. 보완: {조치}" |
| "문제 없습니다" / "이상 없음" | "{축} {n}/{n} 실행 PASS" (실행 증거 동반) — 미실행 축은 별도 ERROR 행 |
| "정상 동작할 것입니다" / "동작합니다" (실행 없이) | "**미실행**. 실행 증거 없음 → ERROR" |
| "테스트 통과" (환경 오류인데) | "**ERROR — 테스트 환경 파손으로 실행 불가**(로직 판정 아님)" |
| "적용했습니다" (사내만 하고 클라우드 미적용) | "사내 적용 완료 / **클라우드 QA·DEV 미적용 = ERROR**" |
| "전부 확인했습니다" (샘플만 본 경우) | "{표본}/{전체} 확인 — **잔여 {n}건 미확인 = ERROR**" |

> ⚠️ **"아마"·"~일 것"·"~로 보임" 은 검증 결과가 아니라 추정이다.** 추정을 결론 칸에 쓰지 말고 ERROR 행으로 내린다.

## §2 "검증 완료" 판정식 (전부 AND — 하나라도 미충족 = ERROR)

```
검증완료 ==
    (A) ui_gate_runner 전 섹션 실행 && 종합 판정 ∈ {PASS, WARN}
        · WARN 은 **사유가 __asis-mapping__.md 에 기재된 것만** 허용 (기재 없는 WARN = ERROR)
        · ERROR 섹션 1개라도 존재 = 미완료
 && (B) 리포트 3종 경로 첨부 (#125 §7)  — 게이트 / HTTP E2E / CRUD 왕복
 && (C) 리포트가 **최종 코드보다 최신** (§4.3 신선도 규약)
 && (D) 적용 축 전수 명시 — 사내 / 클라우드 QA / 클라우드 DEV 각각 적용 여부
 && (E) 사용자 확인 필요 축을 **미완으로 명시** (시각·조작감은 클로드가 대체 불가)
 && (F) 지정 보완요청 n/n — 러너 섹션 10(REQ 원장 축) PASS && 원장 PENDING 0
        && 보류(USER-DECISION/VISUAL)·클라우드 N 목록을 완료 보고에 전기 (hook #139, 2026-08-20)
```

⛔ (A)~(C) 는 클로드가 **스스로 끝내야 하는** 축이다. (D)(E) 는 끝나지 않았으면 **끝나지 않았다고 쓴다** — "완료" 로 뭉뚱그리지 않는다.
⛔ (F) 는 원장(`Doc/단위테스트_보완대상/보완요청_원장.md`)이 분모다 — 요구 미이행 상태로 (A)~(E) 만 채운 "종합 PASS" 는 문법적으로 성립하지 않는다.

## §3 ERROR 표기 양식 (필수 5칸 — 하나라도 비면 표기 불충분)

```md
| 축 | 상태 | 사유(실측) | 영향 | 보완 조치 |
|---|---|---|---|---|
| 9. 단위테스트 | **ERROR** | jsdom `MIMEType is not a constructor` — 실행 불가 | 배분 산식 **값** 미검증 (로직 결함 여부 불명) | whatwg-mimetype v5 정션 → 재실행 → 24/24 PASS |
| 클라우드 적용 | **ERROR** | QA·DEV 미적용 (패키지만 생성) | 사내에만 반영 — 클라우드 화면은 구 동작 | 사용자 승인 후 QA·DEV **동시** 적용 |
```

- **사유는 실측 문구**로 쓴다 (에러 메시지 원문 / 카운트 / SQL 결과). "안 됨" 금지.
- **영향** 칸은 "무엇을 아직 모르는가" 를 쓴다. ERROR 의 본질은 **무지의 선언**이다.
- 보완 조치를 즉시 수행 가능하면 **수행 후 재판정**하고, 승인이 필요하면 승인 요청까지가 보고다.

### §4.2 수동 축 — 자동화로 대체 불가

| 축 | 담당 | 미완 시 |
|---|---|---|
| 사내 Oracle 적용 | 클로드 | ERROR |
| **클라우드 QA·DEV 동시 적용** | 클로드(승인 후) | ERROR — "사내 적용"을 "적용 완료"로 쓰지 말 것 |
| 브라우저 시각·조작감 | **사용자** | 미완으로 **명시** (ERROR 아님 — 클로드 책임 밖. 단 "완료"로도 쓰지 않는다) |

### §4.3 리포트 신선도 규약

리포트 생성 시각 < 대상 소스 최종 수정 시각 → **그 리포트는 증거가 아니다**.

```bash
find {페이지폴더} -name "*.ts*" -newer {리포트경로}   # 결과 0건이어야 유효
```

0건이 아니면 ①재실행하거나 ②**해당 파일이 그 섹션의 검사 축 밖임을 근거와 함께 명시**한다. 침묵 금지.

## §5 게이트를 믿기 전에 게이트를 검증한다 (도구 자기검증 의무)

> **명제**: 통과했다는 사실은, 검사했다는 사실을 증명하지 않는다.

새 게이트·새 검사 축을 도입하거나 개정하면 **반드시** 다음을 먼저 수행한다:

1. **역재현** — 수정 **이전** 코드(`git stash` / HEAD 버전)로 돌려 **결함이 FAIL 로 잡히는지** 확인. 안 잡히면 게이트가 무의미하다.
2. **커버리지 실측** — 검사 대상 총 건수 ↔ **실제 판정된 건수**를 대조. 정규식 미매칭으로 조용히 빠지는 행이 없는지.
3. **절단 고지** — 도구가 상한(top-N/head/limit)으로 자르면 **잘렸다는 사실을 출력**해야 한다. 전체 건수만 찍고 일부만 보여주는 것은 **은폐**다.

### §5.1 조용한 통과 3형 (실측된 은폐 메커니즘 — 발견 즉시 결함으로 취급)

| 형 | 증상 | 탐지 |
|---|---|---|
| **정규식 미매칭 무시** | 표 행이 패턴에 안 걸리면 검사 대상에서 **조용히 빠짐** → "20/20 PASS" 가 실제로는 6건만 검사 | ID 유사 문자열 가드(`RE_ID_LOOKALIKE`) + 총건수 대조 |
| **무고지 절단** | `rows[:200]` 등으로 잘라놓고 전체 건수만 표시 | 출력에 `⚠ n행 생략` 강제 |
| **빈 catch** | `.catch(() => {})` 가 ORA-00904 를 사용자·콘솔·게이트 어디에도 안 남김 | check-ui-gates **G-F** |

## §6 환경 오류(ERROR)는 통과가 아니다

테스트·검증 도구가 **실행 자체에 실패**하면 로직 판정이 아니므로 FAIL 이 아니지만, **PASS 는 더더욱 아니다.**

```
실행 실패 → ERROR 표기 → 환경 복구 → 재실행 → 그때의 결과로 재판정
```

⛔ **"환경 문제라 테스트를 건너뛰었습니다" 로 완료 선언 금지.** 환경 복구까지가 작업 범위다.

### §6.1 계보 — DMF0082 (2026-08-08, 본 hook 신설 계기)

| 사건 | 실측 | 교훈 |
|---|---|---|
| 단위테스트가 **환경 파손으로 미실행** | jsdom `whatwg-mimetype` 버전 불일치 + react 물리중복 19건 | 미실행 기간 동안 테스트가 **조용히 낡음** — 복구하자 13건 실패가 드러남 |
| 대사표 게이트가 **200+11행을 조용히 무시** | 제약 ID `A-15`/`P-23`, EID `E01-A` 가 구 정규식에 미매칭 | "20/20 PASS" 는 **6 EID 만** 검사한 결과였음 |
| 진단 스크립트 **200행 무고지 절단** | 전체 건수는 출력, 표시는 200행 | 사용자가 지적해서 발견 — **도구가 스스로 고지해야** 함 |
| 측정 순서 오류로 **"변화 없음" 오판** | `@sesUserId` 치환 후 정규식 적용 → 치환 0회 | 자기 측정도 **역재현으로 검증** |
| 게이트 섹션 9 = **ERROR 인 리포트**로 완료 선언 직전까지 감 | 22:41 리포트 ERROR → jsdom 복구 후 23:25 재실행 24/24 PASS | **ERROR 리포트 첨부 = 미완료** (§2-A) |
