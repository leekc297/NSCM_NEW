## §1. 원칙 (4대)

개발자가 **보고 바로 개발할 수 있고**, 현업/QA 가 **읽고 바로 이해할 수 있는** 문서.
1. **전수·실측** — 나열식 요약 전재 금지. AS-IS 평문 정본 + 사내 DB 실측만. 추측 0 (anti-simplification).
2. **UI + DB 동시 분석** — 화면 UI 뿐 아니라 AS-IS 소스가 쓰는 DB 계층(SP·PKG·Function·Lookup·Combo·권한·Division·일자/편집 제약)을 함께 전수 분석(§1.5). 분석은 전수로 하되, **문서에는 그 결과를 자연어로 풀어 쓴다**.
3. **가독성 = 전면 자연어** — 각 항목을 **사람이 대화하듯** 설명. 원시 코드 표현(예: `clbDivisions.ControlValues.Substring(0,2)=="81"`, SQL 문장, `.cs` 라인번호)을 그대로 옮기지 않는다. **식별자(SP/PKG/FUNCTION/COLUMN/SHEET/MSG ID/테이블명)만 원문**으로 남긴다. 별도 "쉬운 설명" 열·"줄" 열은 만들지 않는다.
4. **정직한 격차·공백 표기** — "검증 없음/분기 없음/미구현/비활성"은 핵심 가치. 없는 것을 지어내지 않고, 자료 간 수치가 다르면 **양쪽을 병기**하고 확인 필요로 남긴다.

원천 3원: ① AS-IS 평문 정본 전수(추측 금지) ② 사내 메타/SP **실데이터**(ora.py SELECT) ③ TO-BE 현재 구현 + 실측 효과.
⚠️ **Figma = 디자인 참조 only** — LAYOUT 이미지/배치 참조일 뿐 정책 확정 룰 아님(권한/편집/필수값/Validation/콤보 값 등 정책 판단 금지). 상세 = `figma-layout-parity-mandatory` §1.5.

## §1-A. 7시트 구성 (DMF0043 v1.0 = 신 표준 마스터 견본)

| # | 시트 | 필수 내용 (전면 자연어) |
|---|---|---|
| 1 | 개요 | 화면 정의(ID/명/도메인/**메뉴경로=MNU_M walk-up 실측**/업무 목적/AS-IS 폼/TO-BE 경로/대상 Division/화면 성격/주요 SP/제외 범위) + 개정 이력. "항목 / 내용" 2열, 내용은 자연어 문장. |
| 2 | LAYOUT | 메인 + **사용 팝업 전부** 이미지 + 진입경로 + **화면 구역 설명**(조회영역/그리드/버튼)을 자연어로. **이미지 우선순위(2026-07-15)**: ① **Figma 캡처 우선**(`Doc/_figma/_images/{ID}.svg` 존재 시) → SVG 는 headless Chrome/Edge 로 PNG 변환(`chrome --headless=new --screenshot --window-size=W,H`; cairosvg 는 Windows DLL 문제로 불가) ② Figma 없을 때만 **AS-IS 캡처**(`Doc/ui_cap/asis_{id}.png`) ③ 둘 다 없으면 와이어프레임. |
| 3 | 조회조건·버튼 | 조회조건 전수(역할·필수 여부·현재 활성/비활성·연쇄(cascade) 종속) + 버튼 전수(연결 동작·연결 SP·표시/권한 규칙). 모두 자연어 서술. **줄·쉬운설명 열 없음**. |
| 4 | GRID | 그리드 구조를 자연어로: 고정(freeze) 기준 컬럼(관리자 SHEET_COLUMNS 유래) + **동적/PIVOT 컬럼 규칙**(생성 기준·헤더 묶음·편집/읽기 구분) + 콤보·색상·계층 머지. 컬럼은 **식별자 + 자연어 설명**. |
| 5 | EVENT | AS-IS 이벤트 **전수**(F-key 포함)를 "언제 / 무엇이 / 어떻게 동작하나요" 형태의 자연어로. 셀편집·저장(bulk)·팝업 열기·연/월 전환 등 실제 발생 순서를 풀어 서술(메서드·라인 미표기). |
| 6 | VALIDATION | **프로그램(P/G) 검증 + PKG/SP 검증을 한 시트에 취합**. (A) 화면 검증(MSG ID + 언제 + 무엇을) (B) SP 검증(명시적 RAISE + 암묵 분기·파생 규칙 — 없으면 "없음" 명기) (C) **Division별·권한별·기타 축**으로 묶어 제시(없는 축은 "갈라지지 않음"으로 정직 표기). |
| 7 | API·SP | 화면이 부르는 API·프로시저 전수 — API_ID(배선 이름) ↔ 프로시저(실제 DB 오브젝트) ↔ 종류 ↔ **무엇을 하나요(자연어)** + AS-IS↔TO-BE 파라미터 변형 + 다루는 테이블 + PKG/standalone 구조. |

## §1.5. AS-IS 소스 DB 계층 전수 분석 (의무 · 시트 6·7 원천 — 불변)

화면이 실제 호출하는 DB 객체를 **전수 실측**(FE metadata-driven 이면 `SCM_ADM_API_M`/`PROC_M` 경유 standalone SP 확정):
- **SP/PKG**: 화면 실사용 SP `ALL_SOURCE`/AS-IS 원문 전문 덤프 → 검증·분기·파생 규칙 전수 추출(SP당 병렬 에이전트). PKG 멤버/standalone 구분 표기.
- **Function**: SP 소스 grep 으로 `FN_*` + 호출 `PR_*`(side-effect) 전수.
- **Lookup/Combo**: SP 참조 `LOOKUP_TYPE` 전수 → `SCM_ADM_LOOKUP_MASTER_DETAIL` 실측 / `SCM_ADM_CMBO_SQL_M` 원천 SQL.
- **권한/Division/일자/편집**: `SCM_ADM_USER_GR_*`/`SCM_MST_DIVISION`/`SCM_SYS_CALENDAR_M`/`SHEET_COLUMNS` 편집플래그 실측.
- 추출 결과는 **6.VALIDATION(취합 축) + 7.API·SP** 에 자연어로 반영. (구 8·9시트 대체)

## §2. 자연어 서술 규칙 (구 "가독성 의무" 대체)

- **문서 전체가 자연어.** 각 시트 상단에 "이 시트는 무엇을 담고 어떻게 읽는지" 1줄 안내(단, "쉬운 설명"이라는 표현은 쓰지 않는다).
- **남기는 것 = 식별자만**: SP명·PKG명·FUNCTION명·COLUMN명·SHEET명·MSG ID·테이블명·라우트 slug. 이들은 원문 그대로.
- **없애는 것**: 원시 코드 표현식/SQL 문장/`.cs`·SP 라인번호/메서드 호출 체인/별도 "쉬운 설명" 열/"줄" 열.
- **생성일 고정(2026-07-15)**: 1.개요·개정이력의 문서 생성일은 **실제 작성일을 고정 기입**(동적 "오늘"/`today()` 금지 — 재생성해도 값 유지).
- 서식(권장): 제목 14bold #1F4E79 / 섹션바 #1F4E79 / 헤더 #4472A8 / 본문 wrap·thin border / 시트 gridline off·freeze. openpyxl 생성.

## §3. 개발용 상세동작 MD (선택 — 신 표준에서 비의무)

- 구 표준의 `{ID}_{화면명}_상세동작_개발용.md`(메서드·라인 상세)는 **선택 산출**. 화면설계서 자체가 자연어로 동작을 담으므로 필수 아님. 필요 시(복잡 이벤트 다수) 기술 상세 보조 문서로만 작성.

## §4. 생성 기술 표준

- python **openpyxl**(+Pillow) — 스크립트 scratchpad, UTF-8. 대량 제약/이벤트 추출은 **병렬 에이전트** → 자연어 반영.
- 메타 컬럼명은 **ALL_TAB_COLUMNS 동적 발견**(추측 ORA-00904 방지). 이미지 = OneCellAnchor.
- 산출: `Doc/화면설계서/{ID}_{화면명}_화면설계서_v{N}.xlsx` — 잠김 시 버전업 + 개정이력.

## §5. 카운트 대사 (anti-simplification 게이트 — 보고 의무, 불변)

1. 조회조건·버튼·이벤트·GRID 컬럼(SHEET_COLUMNS)·VALIDATION·API 를 **AS-IS 인벤토리 / `__asis-mapping__.md` 와 카운트 일치** 확인·보고.
2. **VALIDATION**: 프로그램 검증 전건 + SP 검증(RAISE 전건, 없으면 "0건 — 없음" 명기) + 취합 축(Division/권한/기타) 정직 표기.
3. **API**: API_M 전수(화면 본체 + 사용 팝업). standalone/PKG 구분.
4. 자료별 수치 차이 **병기**(은폐·임의 단일화 금지).
5. 생성 후 openpyxl 재오픈 assert: **시트 정확히 7개** / 이미지 삽입 / **"쉬운 설명"·"줄"·"소스라인" 헤더 0건** / 원시 코드 표현 미포함(식별자만) / 각 시트 데이터 행 존재.
