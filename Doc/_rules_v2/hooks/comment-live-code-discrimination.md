> **트리거**: 소스(AS-IS `.cs`/`.sql`, `ALL_SOURCE` 덤프, 변환 SQL, FE `.ts(x)`)에 대해
> ①grep/카운트를 **근거로 인용**하려 할 때 ②코드를 **변환·이식·패치**하려 할 때 — 예외 없이.
> **신설**: 2026-08-18 사용자 명시 — "주석인지 라이브인지를 제대로 확인하지 않고 주석 부분을
> 가져와서 적용하는 케이스가 있습니다. 이 부분은 기본적인 부분입니다. **주석은 분석에서도,
> 적용에서도 제외**되도록 해주세요. 강력한 RULE 로 적용 요청합니다."

## §1. 절대 룰 (Hard Rules)

| # | 룰 |
|---:|---|
| 1 | ❌ **주석 코드를 분석 근거로 인용 금지** — grep/카운트 결과를 증거로 쓰려면 각 히트를 `[LIVE]` / `[COMMENT]` 로 **분류 완료한 뒤의 LIVE 만** 센다. 분류 없는 카운트는 증거 무효. |
| 2 | ❌ **주석 코드를 변환·이식·패치 대상으로 삼기 금지** — AS-IS 주석은 TO-BE 에서도 주석(또는 부재)이다. 주석을 활성으로 살리는 것은 **명세 변경**이며, 사용자 명시 지시 없이는 금지. |
| 3 | ❌ 반대 방향도 금지 — **라이브 코드를 주석으로 오독해 "AS-IS 에 없다" 판정** 금지 (파리티 판단이 반대로 뒤집힌다). |
| 4 | ✅ 근거 보고 시 라인 인용에는 **주석/라이브 판정을 함께 명기** — "L3243 (❌주석블록)" / "L3017 (✅라이브)". |
| 5 | ✅ 대량(10개소 이상) 판정은 육안 왕복 대신 **주석 제거 전처리** 후 재-grep 이 정본 — `_artifacts/_diagnostics/strip_code_comments.py` (라인 번호 보존형, §3). |
| 6 | ⚠️ 주석의 **문서 가치는 배제하지 않는다** — 의도·사고 마커·요구 ID(`[E2026…]`)를 읽는 것은 권장. 금지되는 것은 주석을 "동작하는 코드"로 취급하는 것뿐이다. |

## §2. 언어별 주석 문법 — 판별 시 전부 고려 의무

| 언어 | 라인 주석 | 블록 주석 | ⚠️ 함정 |
|---|---|---|---|
| SQL / PL-SQL / T-SQL | `--` | `/* … */` (수백 줄 스팬 가능) | ① 문자열 리터럴 안의 `'--'` / `'-'` 는 주석이 아니다 — **이 프로젝트 센티널 `IN ('-','--')` 가 정확히 이 형태** ② `/*+ … */` 옵티마이저 **힌트는 기능 코드**다(제거·주석 취급 금지 — PERFHINT 계보) |
| C# (AS-IS .cs) | `//`, `///` | `/* … */` | 문자열 `"…//…"`, verbatim `@"…"` |
| TS/TSX | `//` | `/* … */`, JSX `{/* … */}` | 템플릿 리터럴 안 `//` |

**블록 주석 판별법**: 히트 라인만 봐서는 알 수 없다 — `/*` 가 수십~수백 줄 위에서 열렸을 수 있다.
①히트 지점에서 **위로 스캔**해 미닫힌 `/*` 유무 확인, 또는 ②§1-5 전처리 후 재-grep (정본).
`ALL_SOURCE` 덤프도 동일 — DB 에 배포된 소스라고 전부 라이브가 아니다.

## §3. 실행 보조 — 주석 제거 전처리기 (라인 보존형)

`python _artifacts/_diagnostics/strip_code_comments.py <파일> [--mode sql|cs]`
- 주석 문자를 **공백으로 치환**해 라인 수·라인 번호를 원본과 1:1 보존 → 전처리본 grep 라인 = 원본 라인.
- 문자열 리터럴(`'' 이스케이프`·`"식별자"`) 보존, `/*+ 힌트 */` 보존(기능 코드).
- stdout 또는 `<파일>.live` 출력. 분석 스크립트에서 import 하여 `strip_sql(text)` 직접 호출 가능.

## §4. 게이트 연동

- **대사표/파리티 판정**: AS-IS 근거 라인을 인용하는 행은 §1-4 판정 표기가 없으면 게이트 실패 취급.
- **SP 변환·패치 diff 리뷰**: 원본 주석 라인이 결과물에서 활성으로 바뀐 diff = 즉시 중단·사용자 확인
  (MRFPARITY 계보 — "주석 부활" 은 기능 변경이다).
