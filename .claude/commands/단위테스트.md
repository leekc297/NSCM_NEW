# /단위테스트 — 화면 단위테스트 TestCases 생성

대상 화면 = **$ARGUMENTS**

DMF0082 / DMF0003 에서 수행한 절차를 **그대로** 반복한다. 산출물 = `Doc/단위테스트/{화면ID}_{화면명}_TestCases.xlsx` (단일 시트 `TestCases`, 10열).

> ⚠️ **anti-simplification 최우선.** 원천을 요약본으로 대체하거나 영역 일부만 도출하는 것은 금지.
> hook #105 §0: 단위테스트는 화면설계서·UI분석서에 넣지 않고 **별도 TestCases 산출물**로 관리한다.

## Step 1. 원천 인벤토리

```bash
find . -iname "*{화면ID}*" -not -path "./.git/*" -not -path "*/node_modules/*"
find nscm-fe/features -ipath "*{TO-BE 폴더명}*" -type f
```

확보 대상 (없으면 "부재 — 근거 불가"로 정직 표기):

| # | 원천 | 위치 |
|---|---|---|
| 1 | UI분석서 (최신 v, 10시트) | `Doc/화면분석서/{ID}_*_UI분석서_v*.xlsx` |
| 2 | 0단계 선행 산출물 | `{ID}_*_주요이벤트_상세분석.md` / `{ID}_*_제약매트릭스_상세.md` |
| 3 | 상세동작·상세분석서 | `{ID}_*_상세동작_개발용.md` / `{ID}_*_상세분석서_v*.md` |
| 4 | TO-BE 구현 | `nscm-fe/features/{layer}/src/pages/{folder}/` **전 파일** + `__asis-mapping__.md` |
| 5 | 적용 SQL 아티팩트 | `_artifacts/_apply_corporate/{ID}_*` (MSG 등록 / CMBO / 배선 / SP) |
| 6 | 화면설계서 (있으면) | `Doc/화면설계서/{ID}_*.xlsx` |

## Step 2. 전수 Read (요약 대체 금지)

- UI분석서는 **10시트 전량 덤프** 후 읽는다 (openpyxl → 텍스트).
- TO-BE 구현은 **Page / constants / store / Form / Grid / utils / modals 전부**. 부분 grep 로 대체 금지.
- SQL 아티팩트에서 **MSG_ID 별 KO 실문구**를 뽑는다 — 기대 메시지의 단일 근거.
  `grep -h -o "MSG00[0-9]\{3\}'[^)]\{0,180\}" _artifacts/_apply_corporate/{ID}_*.sql`
- SAVE SP 의 **결과 커서 컬럼명**(RESULT_CODE/CODE 등)을 확인해 FE 판독 키와 대조 → 불일치 시 격차 TC 로 남긴다.

## Step 3. 기대값 규칙

1. **대상은 TO-BE 화면.** 메시지는 사내 등록 SQL 실문구 그대로, `비고` 에 AS-IS 원 ID 병기 (예: `AS-IS MSG00002 → TO-BE MSG00429 재매핑`).
2. 실데이터 의존 항목(콤보 실목록, 계정별 권한 조합)은 값 대신 **규칙**으로 서술하고 한계를 밝힌다.
3. **미구현·미사용·격차는 반드시 TC 로 남긴다.** 항목명 앞에 `⚠`, 확인 사항에 현행 동작을, 비고에 근거와 결정 이력을 적는다. 숨기지 않는다.

## Step 4. 영역 설계 (12 표준 + 화면 특성 가감)

| 코드 | 영역 | 필수 포함 |
|---|---|---|
| A | 화면진입 | 메뉴 경로 / 조회조건 기본값 / 버튼 구성(권한별) / 커스텀 버튼 / 코너 헤더 |
| B | 조회조건·연동 | 콤보 cascade / division 전용 조건 / Bucket·체크박스 / 팝업 필드 |
| C | 조회검증·실행 | 필수·기간 검증 전건 / 버킷별 조회 / 0건 / 색·포맷·강조 |
| D | 그리드표시·개인화 | 드릴다운 / Column·Measure 설정 / Sort·Filter / Excel / 머지·헤더높이 |
| E | 편집권한·잠금 | 권한 게이트 / 행 EDIT_FLAG / 실적구간 / 버킷 정합 / 특수 잠금(M+4·RMA 등) |
| F | 신규행·삭제 | Insert 게이트·시드·cascade / 중복 실시간 검사 / Delete 분기 |
| G | 수량 배분·재계산 | 일↔주↔월 전 분기 / 기본요일 / 잔량 / 단가(LOC) 특수 규칙 |
| H | 저장 | 화면 검증 전건 + 확인·성공 + **SP 검증 문구 전건** + 실패 표출 |
| I | 팝업/부가기능 | 화면 전용 팝업(일괄입력·PR·환율 등) 검증·저장 전건 |
| J | 비교·결과 팝업 | 트리거 조건 / 미충족 시 무동작 / 표시 항목 |
| K | Division 분기 | 사업부별 키 컬럼·원장·편집 가부 |
| L | 기타·회귀 | 멀티탭 격리 / 조회조건 저장 / 대량 조회 / 미이관 기능 정직 표기 |

화면에 없는 영역은 삭제하지 말고 **"해당 축 없음"** TC 1건으로 남긴다.

## Step 5. xlsx 생성 (openpyxl, 스크립트는 scratchpad)

포맷은 `Doc/DMF0004_SalesSite_TestCases.xlsx` 승계 — 임의 변경 금지.

- 시트 1개 `TestCases`, 헤더 10열:
  `No | TC_ID | 영역 | 테스트 항목 | 사전 준비 | 화면 조작 절차 | 입력값 | 화면에서 확인할 사항 | 표시되는 메시지 | 비고`
- TC_ID = `TC-{화면ID}-{영역코드}{3자리}` (영역별 연번)
- 서식: 헤더 `F2E1D9` 채움 + 11pt 굵게 가운데 / 본문 11pt 맑은 고딕 wrap·상단정렬 / 얇은 테두리 `BFBFBF` / `freeze_panes='A2'` / gridline off / autofilter 전체
- 열폭: `5.625 / 20.625 / 16.625 / 38.625 / 30.625 / 55.625 / 22.625 / 60.625 / 32.625 / 35.625`
- 서술: 절차는 `1) … 2) …`, 확인 사항은 `• ` 불릿, 메시지는 `MSGxxxxx : 문구`, 없으면 `없음`

산출 경로: `Doc/단위테스트/{화면ID}_{화면명}_TestCases.xlsx`
(파일이 열려 있어 저장 실패하면 `_v2` 로 저장하지 말고 사용자에게 알린다.)

## Step 6. 검증 + 카운트 대사 (보고 의무)

재오픈 assert:
- 시트 1개 / 데이터 행 = TC 수 / 10열 / **빈 셀 0** / TC_ID 중복 0 / freeze `A2` / autofilter 존재

커버리지 대사 (스크립트로 계산해 수치로 보고):
- **화면 검증 MSG 전건** ↔ TC 등장 여부 (`미커버: 없음` 이어야 통과)
- **SP 검증 문구 전건** ↔ TC 등장 여부
- 이벤트·버튼·조회조건 인벤토리 수 ↔ 해당 영역 TC 수

## Step 7. 보고 양식

```
{화면ID} TestCases — 총 N건 / 12영역
영역별 표 (건수)
근거: 문서 원천 / TO-BE 구현 / 적용 SQL (각 링크)
카운트 대사: MSG a/a · SP 검증 b/b · 빈 셀 0 · ID 중복 0
발견한 격차·결함 (있으면 번호 매겨 TC_ID 와 함께)
한계: 실측 불가 항목 명시
```

## 금지 사항

- ❌ 원천 일부만 읽고 TC 도출 (요약본·grep 만으로 대체)
- ❌ 영역 축소 / "대표 케이스만" 샘플링
- ❌ 메시지 문구를 fallback 문자열·기억으로 기입 (등록 SQL 실측만)
- ❌ 격차·미사용 기능 은폐
- ❌ TestCases 를 UI분석서·화면설계서 안에 시트로 추가 (hook #105 §0 위반)
